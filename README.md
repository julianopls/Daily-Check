## 📌 Visão Geral

O **Daily Check** é uma aplicação web criada para auxiliar usuários no gerenciamento de atividades do dia a dia de maneira simples e eficiente.

A plataforma permite cadastrar tarefas contendo informações como:

- Título
- Descrição
- Data de início
- Data final
- Imagem ilustrativa

O sistema realiza o consumo de uma API REST local para armazenamento e manipulação dos dados, oferecendo uma experiência dinâmica e intuitiva.

✔️ Cadastro de tarefas

✔️ Upload de imagem via URL  
✔️ Integração com API REST

# ⚙️ Instalação e Execução

## 1️⃣ Clonar o repositório

```bash
git clone https://github.com/julianopls/Daily-Check.git
```

---

## 2️⃣ Acessar a pasta do projeto

```bash
cd Daily-Check
```

---

## 3️⃣ Instalar as dependências

```bash
npm install
```

---

## 4️⃣ Iniciar o servidor

```bash
npm start
```

ou

```bash
node server.js
```
